## 二、裝機步驟

1. 取 IPA：GitHub Actions 最終 run 的 artifact `AcousticReference-unsigned-ipa` 下載解壓，核對大小與該 run 的 digest。
2. IPA 送進 iPhone（SideStore／AltStore 的檔案入口或 AirDrop 至「檔案」）。
3. 安裝後首次開啟：確認不閃退、首幀為調音頁（頻閃主顯示）、語言為繁中。
4. 麥克風權限：首次點「開啟麥克風校音」→ 系統彈窗允許。
5. 若裝的是替代驗收：先以 `tools/backup-fixture-v1.json` 在設定 → 系統設定 → 數據備份實匯一次，逐項核對（收藏 3 件含自訂巴松、預置 2 組、語言變日文後再改回、主題深色、玻璃 72、A4 440.5、純律主音 G）——驗畢再匯 Laurent 的真實備份。

## 三、實機驗收清單（階段 7「待裝機」子集，逐項勾）

### 調音
- [ ] 信號發生器／調音器 App 輸入 440.0、442.0 Hz：讀數誤差 ≤ ±0.1¢
- [ ] 1568 Hz（G6）輸入：記錄實際偏差（判定插值改進是否需要）
- [ ] 薩克斯實吹 ff：削波警示出現、讀數不跳八度
- [ ] pp 弱音長音 10 秒：不被噪聲門吞（必要時切「安靜琴房」檔）
- [ ] 純律：切主音後錶盤與 Drone 讀數一致（偏差 0）
- [ ] 頻閃：旋轉方向（sharp 順時針，常數可翻）、轉速手感、低音（如 A1）慢轉是否可讀
- [ ] 沉浸全屏：點全屏鈕入橫屏、退出回豎屏；切頁／退後台回來不卡橫屏
- [ ] 演奏態＋防誤觸鎖：開關與長按解鎖
- [ ] 同屏模式：雙面板同時在場、節拍器響的同時吹音看讀數；6.1" 與 6.9"（如有）版面不重疊

### 節拍器
- [ ] 120 BPM 連跑 60 分鐘：診斷頁 interval 統計（mean／max 偏差）記錄；外錄比對無可感漂移
- [ ] Live Activity：開始後靈動島／鎖屏出現、逐拍更新、停止即消失、殺 App 後不殘留
- [ ] Gap Click：靜音小節聲／震同步靜默、視覺照常
- [ ] 背景：鎖屏後節拍與 Drone 續播、鎖屏控制可用

### 中斷與系統
- [ ] 來電／鬧鐘打斷後：調音檢測、節拍器、Drone 按策略自動恢復（或見明確提示）
- [ ] 拔有線／藍牙耳機：播放類自動暫停不外放突響；插回後行為正常
- [ ] 小組件：桌面添加兩件、深連結三路（tuner／metronome／metronome-start）正確
- [ ] 玻璃不透明度 50 觀感對照（與舊材質版差異是否合意）；四主題（含樂池暗紅）逐一切換
- [ ] 45 分鐘連續使用（麥克風＋主顯示＋玻璃）：機身溫度與流暢度，Energy 檔位事後以 Instruments 抽查
- [ ] 八語言逐一切換：頂欄與分段不擠爆（德／俄長詞重點看）
