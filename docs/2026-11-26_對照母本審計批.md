# 對照母本審計批（2026-11-26 晚，Laurent 點名四項＋按鍵回饋）

Laurent 實機（第一版 2b4e909）點名：收藏特效不一樣、節拍器
加減長按不能連續、推子形狀變了（要 Apple 形狀與質感）、
滑動時數字動效不一樣、按鍵位置不一樣／按不到／沒用。
逐項對母本（md5 1c13f148）核對結果：

## 已修

1. **長按連續（母本 addHoldRepeat 行 12170：340 ms 首發、
   62 ms 連發）**：原生時序邏輯同參數，但驅動手勢是
   DragGesture(minimumDistance: 0)，實機不觸發。節拍器
   四步進鈕（−5/−1/+1/+5）與 A4 步進鈕（HoldRepeatButton，
   同屏步進共用）全改以系統 LongPressGesture 的 pressing
   回調驅動；時序與「 hold 結尾吞單擊」語義不變。
2. **推子（母本 .bpm-fader-rail，注釋原文「iOS Control
   Center capsule」）**：舊原生寬 46、圓角 14 矩形軌＋限值
   籤在左列。重做：寬 57 全圓膠囊軌（Material 底＋母本
   漸層 tint＋雙層描邊＋母本陰影，調整中 brightness＋深影）、
   亮填充改母本漸層（白為主、底緣 #EDF1F9）＋三層深度內影
   （頂緣高光／頂內側陰影／底緣藍調）、字形 23pt 於底 12pt
   隨覆蓋變色（母本同規則）、限值籤改軌上下同軸（10pt
   bold、字距 0.5、textSecondary）。
3. **滑動數字動效（母本注釋：拖動時數字條 1:1 直跟、
   .bpm-live 殺過渡）**：舊原生把拖動連續值先取整再餵
   里程表，數字逐格跳。VM 新增 liveAdjustValue＋
   setBpmFromDrag：推子／轉盤／數字三路拖動全傳連續值，
   里程表三柱位置＝連續值的百/十/個位投影、填充同值直跟；
   放手後走原 spring 收斂（母本「settle 來自環的 spring」）。
4. **按鍵沒回饋（母本 .glass-press：按下 brightness 1.12
   ＋saturate 1.12／0.25 s）**：原生 45 處按鍵此前用 .plain
   零回饋。新增 GlassPressButtonStyle 並換用於六個主視圖
   檔案的按鍵；長按步進鈕另以 repeater.isPressing 驅動
   同式亮斑（其 label 非 Button）。玻璃鏡片內部按鍵不套
   （回饋由鏡片動畫給出）。
