# 液態玻璃全量替換批（2026-11-26 晚，Laurent 指示）

Laurent 指示（原話遞進）：「液态玻璃部分全部替换」「做好
做精」「尤其是细节」「所有能换的地方都换」「我要完全适
配液态玻璃」「且效果再做好一点」「参照最新 ios27」「所
有细节」。基準＝iOS 27 系統液態玻璃本體，非仿製材質。

## 替換內容

1. **GlassSurface 全量重寫（全 App 37 處玻璃背景的單一
   入口）**：撤除舊制三層疊加（glassEffect＋白色覆蓋層＋
   手繪描邊）——覆蓋層是第一版實機「乳白磨砂、一坨」的
   元兇。新版單層純 glassEffect：折射、鏡面高光、邊緣
   光暈全由系統本體給出。回退用的 MaterialGlassSurface
   一併刪除（全量替換，不留仿製後路）。
2. **tint 配方對齊 iOS 27**：新增 TunerTheme.glass 工廠
   為全 App 統一配方——tint alpha = 0.02 + 0.34t（不透
   明度 8–96 映射，預設 50 → ≈0.18）。重 tint 會把玻璃
   悶成塑料（第一版的病），系統玻璃的清透感來自克制。
3. **推子軌道**：原 Material＋漸層 tint 仿製疊層 → 純
   glassEffect 膠囊（深 白 0.14／淺 中灰 0.16 染）；母本
   軌邊 1px 與陰影、調整中變亮保留。
4. **樂器卡**：原平色填充（深 白 0.04／淺 白 0.5）→ 真
   玻璃；選中態 accent 淡色墊於玻璃之後襯色＋既有 accent
   描邊，不覆蓋玻璃面。
5. **調音頁讀數格**（Hz／音分格）：平色填充 → 真玻璃。
6. **拍點 L1**：玻璃圓點上的手繪描邊撤除（邊緣由本體
   給出）。
7. **整體即玻璃的按鍵改 interactive 玻璃**：頂欄鎖定／
   診斷圓鈕、收藏列「＋常用」膠囊——glassEffect 直接落
   在按鍵本體並開 interactive，按壓形變由玻璃本體給出
   （iOS 27 系統圓鈕同式）。面板／列級背景維持非互動
   玻璃（系統同理：面板不形變）。
8. **原本已是真玻璃的部分核對保留**：分段鏡片
   （glassEffectID morph）、晶片選中態（accent tint＋
   interactive）、Toast 膠囊、沉浸頁／同屏／設定各面
   （全經 GlassSurface 統一入口，隨 1. 自動升級）。
