  - frozen＋無統計：`⏸ 已定格 · 轻点继续`

## 3. 收藏星星爆裂 `burstStar`

### 觸發條件（`toggleFavoriteInstrument`，行 6783–6804）

### JS 全文參數（行 6805–6835；v17 按 Laurent 要求恢復，註釋明載）

**星星本體彈跳**（WAAPI `btn.animate`）：

- keyframes：`scale(1)` → `scale(1.28)`（offset 0.35）→ `scale(1)`
- `duration: 300ms`；`easing: cubic-bezier(0.34, 1.56, 0.64, 1)`（過衝彈簧）

- 角度：`ang = (2π × i / 6) + 0.4` rad（i＝0…5，整體旋轉偏移 0.4 rad）

## 4. 背景按壓亮斑 `#pageGlow`

Laurent 所述「原版背景手指按下去會跟著手指滑動亮」即此層——全頁液態光：按下時玻璃面在指尖處亮起，拖動時 1:1 跟隨，鬆手淡出。

### DOM 與 CSS（DOM 行 5137；CSS 行 1960–1980）

- DOM：`<div id="pageGlow" aria-hidden="true"></div>`，位於背景層（wallpaper／ambient）之後、Toast 之前。
- `.pageGlow` 本體：`position:fixed; top:0; left:0; width:340px; height:340px; border-radius:50%; z-index:1; pointer-events:none; opacity:0; transition: opacity 0.3s var(--ease-out); will-change: transform;` 初始 `transform: translate3d(-400px,-400px,0)`（屏外待命）。
- 漸變（深色）：`radial-gradient(closest-side, rgba(130,175,255,0.15), rgba(255,255,255,0.05) 42%, transparent 70%)`；`mix-blend-mode: screen`。
- 漸變（淺色，行 1977–1980）：`radial-gradient(closest-side, rgba(255,255,255,0.55), rgba(255,255,255,0.12) 42%, transparent 70%)`；`mix-blend-mode: normal`。
- `.on`（行 1976）：`opacity:1; transition-duration:0.12s`——亮起快（0.12s）、熄滅慢（基礎 0.3s）。

### JS 行為（行 12352–12398，監聽 `document`，均 passive）

- `setGlow(x, y)`：`transform = translate3d(x−170px, y−170px, 0)`（340px 圓以指尖為心）。
- `pointerdown`：立即 `setGlow` 到按壓點並加 `.on`。
- `pointermove`：僅 `.on` 期間跟隨；寫入以 `requestAnimationFrame` 合併為每幀至多一次，**即時 1:1 跟指、無緩動／無延遲**（註釋明載 transform-only、與分段鏡片跟隨同成本級）。
- `pointerup`／`pointercancel`：移除 `.on`（按 0.3s 淡出）並取消待處理的 rAF。
- 附帶：同一組 pointer 監聽還驅動 `markInteracting()`（行 12357–12376）——手勢期間給 `<html>` 加 `.is-interacting`（輕量渲染模式），最後事件 180ms 後移除；若分段鏡片仍在飛行中則續延。此為性能機制，與亮斑視覺無關，原生側可不移植。

> 區分：按鈕自身的 `.glass-press` 按壓亮斑與 `is-pressing` 形變是另一套（控件級），本節只含背景級跟隨光。

### 高度分配原則（母本註釋明載，原生對照要點）

1. 物件尺寸恆定：錶盤與所有控件不隨殼高縮放；高度差只由間距與彈性畫布（舞台、軌跡）吸收（行 4046–4052 註釋）。
2. 餘高去向：舞台按內容定高 → 數據卡 `flex-grow` 吸收 → 卡內全給軌跡（上限 128px／高機型 196px）；底部操作行 `margin-top:auto` 貼底（行 3201–3226 註釋）。
3. 高度不足時：軌跡先收縮（下限 52px），控件永不被裁（行 4053–4059 註釋）。
